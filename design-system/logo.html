Usage rules

✓
Fixed stroke. The shield is always #6366f1 on dark, and the same indigo on light. Never recolor it to semantic colors.
✓
Minimum size. Keep the shield at or above 20px; below that use the favicon. The wordmark is always lowercase, sans, 700.
✕
Don't — recolor, fill, add a drop shadow, rotate, or skew the shield. Never stretch it out of the 24×24 aspect.
✕
Don't — use a different glyph, a filled shield, or change the stroke weight. It's always outline, stroke-width 2, round caps.

The mark is the Lucide shield glyph, inlined in the UI at ui/src/components/ui/Logo.tsx. Keep shield.svg (currentColor) as the default in UI; use shield-accent.svg/shield-white.svg only where a fixed tint is required.
