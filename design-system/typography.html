Typography

Inter + JetBrains Mono

Two self-hosted faces do the whole job. Inter (400–700 variable) carries all reading and UI copy; JetBrains Mono is reserved for the cryptographic facts — IDs, links, counters, badges, field hints — so anything that must read as "trust-level detail" is visually distinct.

Font source

--font-sans: "Inter", -apple-system, BlinkMacSystemFont, "Segoe UI", sans-serif;
--font-mono: "JetBrains Mono", ui-monospace, "SF Mono", Menlo, monospace;

Self-hosted at ui/public/fonts/ (Inter latin + latin-ext, JetBrains Mono latin) — also bundled in this kit at assets/fonts/. System UI / ui-monospace are the fallback stacks.

JetBrains Mono

Used for anything that is data, not prose: secret IDs, share links, animated counters, segmented-control labels, badge chips, and field character counts.

Mono vs. sans
s/KcyT8QzO33MJlhvYXq0Q== (mono)
s/KcyT8QzO33MJlhvYXq0Q== (sans)

Reserve mono for the technical layer. Never set body copy in mono — it reads slower and drifts from the brand.

Usage notes

✓
Do — keep headings at 600–700 and body at 400. Set technical/ID detail in var(--font-mono). Use --text-secondary for anything secondary.
✕
Don't — introduce a third family, set body copy in mono, or force negative letter-spacing on body text.
